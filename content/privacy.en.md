# This site

This site is a set of static files built from the
[jumplink.github.io](https://github.com/JumpLink/jumplink.github.io) repository. It has no
accounts, no forms, no comments and no newsletter, so it collects nothing you type. The blog's
Atom feeds are static files too: a feed reader that fetches them reaches the same host as your
browser does and nothing else.

The apps linked from here have their own sites and their own privacy statements.
