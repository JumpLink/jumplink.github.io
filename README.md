# jumplink.eu

Pascal Garber's site: his apps, a blog and a CV, in English and German. Live at
[jumplink.eu](https://jumplink.eu/).

The pages are generated by [`@gjsify/site`](https://github.com/gjsify/gjsify/tree/main/packages/infra/site)
from the `gjsify.site` block in `package.json` — the same generator that builds the sites of the
apps linked from here.

| Path | What |
| --- | --- |
| `content/resume.<lang>.json` | The CV, one [JSON Resume](https://jsonresume.org/schema) file per language |
| `blog/<year>/<slug>.<lang>.md` | Blog posts; `draft: true` keeps one out of the build |
| `content/` | Privacy statement and legal notice |
| `assets/` | Avatar and the display font |
| `static/` | Copied over the build as is: `.nojekyll` and the redirect for the old `/support/` |

```sh
gjsify install
gjsify run build          # → _site/
gjsify run build:drafts   # include drafts
```

A push to `main` deploys through GitHub Pages; a daily rebuild picks up changes to the apps.
The previous Riba.js site is kept under the tag `v2-riba`.
