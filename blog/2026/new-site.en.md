For years jumplink.eu was a single-page CV written in Riba.js, my own web framework. It still
works, but it had stopped saying what I spend my time on: [gjsify](https://gjsify.org/) and the
GNOME apps I build with it.

The new site is generated by `@gjsify/site`, the package that already builds the download pages of
[Beifahrer](https://jumplink.eu/beifahrer/) and [Steuererklärung](https://jumplink.eu/steuererklaerung/)
from their AppStream metainfo. It learned two things for this:

- **Developer sites.** Instead of one app's metainfo, a site can describe a person: a hub that links
  their apps, and a CV read from a [JSON Resume](https://jsonresume.org/) file per language.
- **A blog.** Markdown files in git, with frontmatter for title, date and tags. The build writes an
  index, tag pages, an Atom feed per language and per tag, and a link-preview card for every post.

Both are plain configuration in `package.json`, so anyone who builds an app site with gjsify can
add a blog the same way. The pixel font and the crisp, unsmoothed images are a theme option, not a
fork.

The old site is kept in the repository under the tag `v2-riba`.
